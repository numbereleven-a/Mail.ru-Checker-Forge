# Mail.ru Checker Forge для Firefox

Тестовая сборка для настольного Firefox 140 и новее. Доступна временная установка; подпись Mozilla и публикация в каталоге пока не выполнены. Сохранены интерфейс, несколько почтовых ящиков, быстрые действия с письмами, темы, лимит писем и восемь звуков. По умолчанию показываются пять писем для каждого ящика и используется звук «Мягкий pop».

## Проверка сборки

1. Распакуйте ZIP для Firefox.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите «Загрузить временное дополнение» и выберите `manifest.json` из распакованной папки.
4. Разрешите доступ к указанным сайтам Mail.ru, если Firefox запросит его.
5. Войдите в нужные ящики Mail.ru в этом же Firefox в обычных вкладках.

Временное дополнение удаляется при перезапуске браузера. Для постоянной установки нужен XPI с подписью Mozilla. ZIP предназначен для временной установки и подачи на подпись, сам по себе подписанным дополнением не является.

## Отличия браузера

Firefox не поддерживает кнопки в системных уведомлениях расширений. Нажатие на уведомление открывает письмо; пометить письмо прочитанным и удалить его можно в окне расширения. Звуки воспроизводятся фоновой страницей Firefox.

Настройки и авторизация Chrome автоматически не переносятся. Ящики в контейнерах Firefox и приватных окнах отдельно не поддерживаются.

При установке указаны категории данных, необходимые для обмена с Mail.ru: адреса ящиков, сведения авторизации и данные писем. Это не аналитика: расширение обращается к Mail.ru для своей основной функции. Подробности приведены в политике конфиденциальности.

## Сборка из исходников

Запустите `node scripts/build.js firefox`. Готовая папка появится в `artifacts/1.0.1/firefox`. При повторной сборке сначала переместите предыдущую папку. В ZIP должны лежать файлы из этой папки, с `manifest.json` в корне.
