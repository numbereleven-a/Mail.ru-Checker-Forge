# Mail.ru Checker Forge

Это форк [оригинального расширения в Chrome Web Store](https://chromewebstore.google.com/detail/mailru-checker-free/npehpdcondlmfhfhhfmpoiomoalhkfdf?hl=ru&utm_source=ext_sidebar).

Расширение для Google Chrome, которое показывает непрочитанные письма Mail.ru прямо в панели браузера.

> **Чем Forge лучше оригинала:** корректная работа с несколькими ящиками, быстрые действия с письмами и исправления стабильности и безопасности.

## Возможности

- показывает количество непрочитанных писем на значке расширения;
- отображает письма сразу из нескольких подключённых ящиков;
- открывает нужный ящик или конкретное письмо одним нажатием;
- позволяет быстро пометить письмо прочитанным или переместить его в «Корзину»;
- поддерживает уведомления и звуковой сигнал;
- предлагает восемь именованных звуков с предпрослушиванием;
- по желанию повторяет сигнал каждые 30 секунд, пока остаются непрочитанные письма;
- позволяет настроить интервал проверки, число писем в списке, звук, интерфейс и тему оформления;
- сохраняет локальное состояние непрочитанных писем для каждого ящика.

## Требования

- Google Chrome 120 или новее.

## Установка из релиза

1. Скачайте ZIP-архив из раздела [Releases](../../releases).
2. Распакуйте архив в отдельную папку.
3. Откройте в Chrome страницу `chrome://extensions/`.
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку.

После установки откройте Mail.ru в обычной вкладке Chrome и убедитесь, что нужные ящики подключены в аккаунте.

## Настройки

Откройте popup расширения и нажмите кнопку с шестерёнкой. Доступны следующие параметры:

- интервал проверки: 30 секунд, 1, 3 или 5 минут;
- число отображаемых писем для каждого ящика: свободное значение от 1 до 100, по умолчанию 5;
- звуковой сигнал при новых письмах;
- обычный или мобильный интерфейс Mail.ru;
- светлая, тёмная или системная тема.

## Разрешения Chrome

- `storage` — хранение настроек и локального состояния писем;
- `notifications` — уведомления о новых письмах;
- `offscreen` — воспроизведение звука в фоновом режиме;
- `alarms` — периодическая проверка почты;
- `idle` — пауза проверки при блокировке или простое компьютера;
- доступ к доменам Mail.ru — получение списка ящиков, счётчиков и писем через Mail.ru.

Расширение не запрашивает пароль от Mail.ru. Запросы выполняются в авторизованном профиле Chrome с использованием сессии Mail.ru.

## Проверка изменений

Автоматический regression-набор проверяет:

- синхронизацию нескольких аккаунтов и обновление списка при неизменившемся счётчике;
- числовые и строковые ID сообщений, папок и счётчиков;
- исключение системных папок из badge, popup и уведомлений;
- атомарное сохранение настроек и инициализацию состояния;
- отсутствие API-токенов в данных popup;
- изоляцию временно скрытых писем между аккаунтами;
- паузу при idle/lock и возобновление проверки;
- обработку HTTP-ошибок, HTTPS-ссылки и минимальные host permissions;
- безопасное построение DOM для данных писем.

Запуск:

```text
node tests/regression.js
```

## Структура проекта

- `background.js` — фоновая логика, опрос Mail.ru и уведомления;
- `popup.html`, `js/popup.js` — окно расширения;
- `options.html`, `js/options.js` — страница настроек;
- `offscreen.html`, `offscreen.js` — воспроизведение звука;
- `tests/regression.js` — автоматические проверки исправленных сценариев;
- `manifest.json` — описание расширения Chrome Manifest V3.
