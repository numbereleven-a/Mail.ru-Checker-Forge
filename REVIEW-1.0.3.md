# Ревью и проверка 1.0.3

Дата: 8 сентября 2026 года. Основа: локальная версия 1.0.2. Проверены фоновая логика, popup, настройки, общие функции, звук и формирование сборок. Ниже перечислены воспроизведённые ошибки корректности и их исправления.

## Исправленные ошибки

| --- | --- | --- | --- |

Счётчик обновляется при изменении списка ящиков. | До исправления появлялось лишнее уведомление; после исправления число уведомлений не меняется. Повторное подключение создаёт рабочий объект ящика. |
| P2 | Ответ NaviData приходил после перехода в простой и запускал запросы для новых ящиков. ## Фактическая проверка

- Регрессионный набор `node tests/regression.js` пройден.
- Все семь сценариев `node tests/review.js` пройдены на исходниках и Chrome-пакете; на Firefox-пакете пройдены шесть применимых сценариев. Проверка создания Chrome offscreen-документа к Firefox не относится.
- Из ZIP-архивов извлечены файлы; их SHA-256 совпадают с файлами сборки и соответствующими исходниками. Манифесты сформированы отдельно для каждого браузера.
- Обе распакованные сборки загружены в отдельные профили: Chrome for Testing 151.0.7922.34 и Firefox 155.0.1.
- В браузерах проверены два ящика, сохранение лимита и тёмной темы, Unicode в теме письма, кнопки «Прочитать» и «В корзину» через обмен сообщениями с фоном, декодирование и воспроизведение всех восьми WAV-файлов и фоновый звук.
- Проверка Mozilla `web-ext lint` для Firefox-пакета: **0 ошибок, 0 предупреждений, 0 замечаний**.
- Скриншоты настроек и popup просмотрены. Протоколы браузерной проверки и изображения находятся в локальной папке `artifacts/1.0.3/verification`.

Браузерные сценарии выполнялись на синтетических письмах с подменёнными ответами API в памяти отдельного профиля. Реальные аккаунты, серверные операции Mail.ru и доставка настоящих уведомлений на рабочий стол не проверялись.

Для запуска браузерной проверки установите тестовые зависимости Playwright для Chrome и Selenium WebDriver для Firefox вне распространяемого дополнения; обеспечьте их доступность Node.js. Затем выполните:

```text
node tests/browser-smoke.js chrome artifacts/1.0.3/chrome artifacts/1.0.3/verification
node tests/browser-smoke.js firefox artifacts/1.0.3/firefox artifacts/1.0.3/verification
```

Для проверки исходников внутри извлечённого архива переменная окружения `FORGE_PROJECT_ROOT` указывает на его папку; сами тесты запускаются из исходного проекта. В обычном запуске эта переменная не требуется.
