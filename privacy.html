Политика конфиденциальности Mail.ru Checker Forge

Обновлено: 19 августа 2026 г.

Mail.ru Checker Forge — это расширение для браузера для уведомления о письмах в Mail.ru. Мы придаем приоритетное значение защите ваших данных.

1. Сбор данных

Расширение не собирает, не хранит и не передает ваши персональные данные на сторонние серверы.

  • Авторизация: Используется текущая сессия браузера. Расширение не запрашивает логин или пароль.
  • Данные: Получаем адрес почты, количество непрочитанных писем и метаданные сообщений (тема, отправитель, дата) через официальный API Mail.ru.
  • Цель: Только для отображения в интерфейсе расширения.
  • Передача: Все запросы выполняются напрямую между вашим браузером и серверами Mail.ru по протоколу HTTPS.

2. Разрешения (Permissions)

  • idle: Приостановка фоновых запросов при простое или блокировке устройства.
  • notifications: Отображение системных уведомлений о поступлении новых писем.
  • storage: Хранение настроек (интервал проверки, звук, интерфейс), кэша состояния почты и кратковременного состояния действий.
  • offscreen: Воспроизведение звуковых уведомлений в фоновом режиме через Offscreen Document.
  • alarms: Периодическая фоновая проверка почты с интервалом, заданным пользователем.

3. Доступ к сайтам (Host Permissions)

  • portal.mail.ru, auth.mail.ru, e.mail.ru: Авторизация и выполнение запросов к API Mail.ru с использованием текущей сессии.
  • mailru-checker-api.e.mail.ru: Получение данных о письмах и папках.

4. Хранение и безопасность

  • Локальность: Информация хранится в хранилищах расширения на вашем устройстве.
  • Безопасность: Взаимодействие с Mail.ru выполняется через защищённый протокол HTTPS.
  • Нет серверов: Расширение не имеет собственного сервера. Вся логика работает на вашем устройстве.

5. Управление данными

  • Вы можете изменить настройки или отключить уведомления в любой момент.
  • Вы можете прекратить доступ, выйдя из учётной записи Mail.ru.
  • При удалении расширения все локальные данные удаляются автоматически.
